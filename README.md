# Star Runner

A lightweight space arcade game built with HTML, CSS, and JavaScript. Collect gold stars for 10 points each and dodge red asteroids as the game gets faster. Your best score is saved in your browser when storage is available.

## Play

Download or clone this repository and open `index.html` in a modern browser. No installation, dependencies, or build step required.

- Move: arrow keys or WASD.
- Touch/mouse: drag inside the game area.
- Pause/resume: P or the Pause button.
- Restart: select Fly again after a collision.

## Checks

JavaScript syntax and simulated gameplay checks passed for starting, movement, collecting stars, pausing/resuming, asteroid collisions, high scores, and restarting. Visual browser testing has not been performed.
